# Task Tracker
## Description :
This script manage tasks by command line and it made to practise my coding skills

### Features
Ability to :
1- Add a Task with its description
2- Mark a Task as done , in-progress and to-do
3- Delete a spicific Task
4- List all Tasks
5- List Tasks based on its Status (done,in-progress,to-do)

### Requirements : 
- PHP interpreter
- command line interface

### Installation :
1- Clone this repo to your computer
2- Run index.php file from CLI

### Usage Examples :
php index.php add "Task 1"
this will add "Task 1" to my list of Tasks on Tasks.json file 

php index.php mark-done 1
this will modify the Status of Task with ID = 1 to done
